# 3D 공간 임베딩 · 지식 그래프 탐색기

> 공간 객체 임베딩과 계층적 지식 그래프를 3D 디지털 트윈 화면에서 함께 탐색하는 PoC 프로토타입입니다.

단독 주택을 예시로, **격자 방식의 공간 임베딩 모델**이 해당 위치와 객체의 특성을 설명하고, **계층적 지식 그래프**가 주변 공간과 객체 간의 위계·인접·유사 관계를 설명할 수 있음을 시각적으로 보여주는 웹 프로토타입입니다.

![데모 화면](https://github.com/thlee33/embeding_ontology_PoC/blob/main/demo.png)

## 1. PoC 목적

공간정보 AI를 실제 서비스 화면에서 설명하려면 단순한 2D 다이어그램만으로는 한계가 있습니다. 이 프로토타입은 다음 질문에 답하기 위해 제작되었습니다.

- 특정 위치나 객체가 어떤 공간 특성을 갖는가?
- 유사한 특성을 가진 공간 객체는 무엇인가?
- 선택한 객체가 상위 공간, 하위 객체, 인접 공간과 어떤 관계를 갖는가?
- 임베딩 기반 유사도와 지식 그래프 기반 관계 탐색을 하나의 3D 디지털 트윈 화면에서 어떻게 함께 보여줄 수 있는가?

## 2. 핵심 개념

### 2.1 격자 기반 공간 임베딩

공간을 50cm 래스터 셀 단위로 분해하고, 각 셀과 공간 객체에 속성값을 부여한 것으로 가정합니다. 각 객체는 16차원 더미 임베딩 벡터를 가지며, 우측 패널에서 히트맵과 스파크라인으로 표현됩니다.

프로토타입에서는 실제 학습 모델을 사용하지 않고, 개념 전달을 위해 더미 벡터와 더미 유사도 값을 사용합니다. 예를 들어 **화장실 A**와 **화장실 B**는 같은 습식 공간이라는 특성을 반영하여 임베딩 공간에서 가장 유사한 객체로 배치됩니다.

### 2.2 계층적 지식 그래프

공간 객체는 다음 위계를 갖습니다.

```text
집
├─ 현관
├─ 거실
├─ 부엌
├─ 공부방
│  └─ 책상
│     └─ 노트북
├─ 안방
├─ 작은방
├─ 화장실 A
├─ 화장실 B
└─ 베란다
```

지식 그래프는 다음 관계를 표현합니다.

| 관계 유형 | 의미 | 화면 표현 |
|---|---|---|
| 포함(contains) | 상위 공간이 하위 공간·가구·사물을 포함 | 굵은 실선 |
| 인접(adjacent) | 공간 객체가 물리적으로 인접 | 가는 실선 |
| 유사(similar) | 임베딩 특성이 유사 | 점선 |

### 2.3 3D 디지털 트윈 연동

지식 그래프 노드는 별도의 2D 그래프가 아니라, 실제 3D 공간상의 객체 위치 상공에 앵커링됩니다. 노드와 객체는 리더 라인으로 연결되어, 사용자가 “그래프상의 관계”와 “실제 공간상의 위치”를 동시에 이해할 수 있습니다.

## 3. 주요 기능

- 3D 단독 주택 모델과 공간별 50cm 래스터 셀 표시
- 공간·가구·사물 객체 선택 및 카메라 fly-to 이동
- 3D 지식 그래프 노드/링크 중첩 표시
- 포함, 인접, 유사 관계별 링크 스타일 구분
- 선택 객체의 속성, 위계 경로, 설명 표시
- 16차원 임베딩 벡터 히트맵 및 스파크라인 표시
- 임베딩 유사도 Top-N 랭킹 표시
- 임베딩 2D 투영 미니맵 표시
- 키워드 검색을 통한 객체 이동
- 3D 모델, 래스터, 그래프 레이어 on/off
- 데모 재생 기능: 화장실 A 선택 → 유사도 랭킹 확인 → 화장실 B 이동
- 그래프 높이, 안개 농도, 래스터 투명도, 노드 발광, 라벨 표시 방식 조정

## 6. 인터랙션 흐름

### 6.1 객체 선택

3D 뷰의 공간, 래스터 셀, 그래프 노드, 좌측 객체 목록, 검색 결과, 우측 관계 칩 중 하나를 클릭하면 동일한 선택 상태가 전체 UI에 동기화됩니다.

```text
객체 선택
→ 3D 객체 하이라이트
→ 그래프 노드/링크 강조
→ 카메라 fly-to
→ 좌측 내비게이터 동기화
→ 우측 정보·임베딩·관계 패널 갱신
```

### 6.2 임베딩 유사도 탐색

화장실 A를 선택하면 우측 유사도 랭킹에서 화장실 B가 최상위로 표시됩니다. 사용자가 해당 항목을 클릭하면 카메라가 화장실 B로 이동하고, 그래프의 유사 관계 링크가 강조됩니다.

### 6.3 지식 그래프 관계 탐색

선택 객체 기준으로 상위, 하위, 인접 관계가 우측 패널에 표시됩니다. 관계 항목을 클릭하면 해당 객체로 이동합니다.

## 7. 활용 가능 분야

이 프로토타입은 단독 주택 예시로 제작되었지만, 동일한 개념은 다음 분야로 확장할 수 있습니다.

- 도시 디지털 트윈 기반 객체 검색
- 건물·시설물 내부 공간 지능화
- 도로, 격자, 건물 단위 공간 특성 임베딩
- 침수, 지반침하, 안전사고 위험지역 유사도 분석
- GeoAI 기반 공간 추천·분류·군집 탐색
- 지식 그래프 기반 시설물, POI, 행정구역, 생활권 관계 탐색
- RAG 기반 공간 질의응답 인터페이스

## 8. 확장 아이디어

향후 PoC를 실제 서비스로 확장하려면 다음 요소를 추가할 수 있습니다.

- 실제 공간 데이터 기반 래스터/벡터 전처리
- 공간 객체별 속성 벡터 생성 파이프라인
- Text Embedding 또는 Graph Embedding 모델 연동
- PostGIS, pgvector, Neo4j 등 저장소 연동
- CesiumJS 또는 MapLibre GL 기반 실제 지도 좌표계 연동
- 자연어 질의 기반 객체 검색
- 유사 객체 추천과 관계 기반 설명을 결합한 GeoRAG 기능
- 다중 건물, 도시 블록, 도로망, 행정구역 단위 확장

## 9. 주의사항

- 본 프로젝트는 개념 검증용 PoC입니다.
- 현재 임베딩 벡터와 유사도는 설명용 더미값입니다.
- 현재 지식 그래프 관계도 단독 주택 예시를 위한 수동 정의 관계입니다.
- 실제 서비스 적용 시에는 데이터 정합성, 좌표계, 객체 식별자, 모델 학습·검증, 그래프 스키마 설계가 별도로 필요합니다.
